# Heart Disease Prediction Streamlit App

An interactive Streamlit application that predicts heart-disease risk using a machine-learning pipeline trained in Google Colab.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Deploy the repository through Streamlit Community Cloud using `app.py` as the main file.

## Disclaimer

This application is for educational and decision-support purposes only. It does not provide a medical diagnosis.
